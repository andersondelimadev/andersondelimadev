### 🚀 Highlighted Projects

#### 🏢 [CondoManage](https://github.com/andersondelimadev/SistemaCondominio) — [live demo](https://sistemacondominio-nine.vercel.app/apresentacao)
> Multi-tenant SaaS for condominium management: admin, front desk and resident portals on a real PostgreSQL backend.

- **Scale:** 12 pages · 38 REST route handlers · 19 PostgreSQL tables · 4 versioned migrations (`node-pg-migrate`) · ~12k LOC TypeScript
- **Security:** bcrypt + JWT in `httpOnly` cookies · role-based access (Manager / Doorman / Resident) enforced in middleware **and** API (`403`) · tenant isolation by `condominio_id` · soft-delete + audit log table
- **Payments:** Mercado Pago PIX with webhook `x-signature` validation · monthly invoices generated by **Vercel Cron**
- **AI:** Google Gemini in 3 features (natural-language booking, incident summaries, executive assistant) behind a per-user daily quota
- **Integrations:** Resend (email) · Twilio (WhatsApp) · QR Code visitor check-in · panic alerts via visibility-aware polling
- **Quality & Ops:** Vitest unit tests · Sentry (client / server / edge) · installable **PWA** (manifest + service worker)

#### 🎮 [Super Smash Bros Museum — Smash Compendium](https://smashcompendium.com/) — [repo](https://github.com/andersondelimadev/smash-compendium)
> Interactive historical archive of the Super Smash Bros. franchise: 90 fighters, 54 franchises and 4,400+ items (trophies, spirits, stickers, soundtracks) from SSB64 to SSBU.

- **Scale:** 18 pages (8 public + 10 admin CMS) · 32 API routes · 14 Prisma models · ~57k LOC TypeScript
- **Performance:** ISR (`revalidate` 10 min – 24 h) · `generateStaticParams` for fighter and franchise pages · tag-invalidated data cache (`unstable_cache`) · 5 route-level `loading.tsx` with **skeleton screens** · lazy-loaded images · idle-time image preloading (`requestIdleCallback`)
- **SEO:** dynamic metadata on 8 routes · `sitemap.ts` + `robots.ts` · Open Graph · custom 404
- **Security:** admin area protected by middleware with signed session cookie · login brute-force lockout · rate-limited AI translation endpoint
- **i18n:** 4 display modes (EN / PT / JP / JP+EN) with AI-assisted translation (Gemini + Claude)
- **Data pipeline:** 50+ ETL scrapers (Playwright, Cheerio, Tesseract OCR, Sharp) feeding S3-compatible storage
- **Observability:** Vercel Analytics + Speed Insights

#### 💼 [Anderson de Lima — Portfolio](https://andersoncrush.dev) — [repo](https://github.com/andersondelimadev/anderson-crush-dev)
